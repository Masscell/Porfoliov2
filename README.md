# Marcel Onoja - Portfolio

A modern, responsive portfolio website built with SvelteKit, showcasing frontend development projects, technical skills, and professional experience.

## Tech Stack

- **Framework**: SvelteKit
- **Styling**: CSS3 with custom animations
- **Icons**: Lucide Svelte
- **Build Tool**: Vite
- **Deployment**: Vercel

## Features

- Responsive design for all devices
- Smooth animations and transitions
- Interactive project showcase with filtering
- Professional experience timeline
- Skills and expertise sections
- Contact form
- SEO-optimized with meta tags

## Getting Started

### Prerequisites
- Node.js 18+ (20 or 22 recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone <repository-url>
cd HNG-Portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

The application will be available at `http://localhost:4001`

### Build

```bash
npm run build
```

This generates production-ready files in `.svelte-kit/output/`

### Preview

```bash
npm run preview
```
